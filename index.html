How NetInfo works

01

Startup

NetInfo opens with its branded boot screen: NET INFO / By Amir-93.

02

Collect

Python reads available local network and system information from the device.

03

Check

The application checks internet reachability and estimates response latency.

04

Display

Results are presented in a graphical dashboard and refreshed automatically.

Android may restrict access to some network values. If a value is unavailable, NetInfo reports it instead of pretending it has been detected.
